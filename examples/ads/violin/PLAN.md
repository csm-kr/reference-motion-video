# Moments 40s: 바이올린 "따로, 그리고 하나"

## 레퍼런스와 고른 이유
**Sony Audio "Music Bridges Us" featuring Ray Chen** (https://www.youtube.com/watch?v=QMcVd2mi9ag). 분석 원문은 `../refs/violin/ANALYSIS.md`.

- 바이올린 독주 하나가 감정을 끌고 간다. 사진·추억 광고 약 45편의 소리를 직접 녹음해 비교했는데, 바이올린이 이끄는 광고는 이것 하나였다.
- 차가운 도시의 청취자와 따뜻한 홀의 연주자를 교차 편집하다가, **바이올린 최고음에서 두 세계가 한 화면에 들어온다**. "각자 찍은 사진이 하나의 Moment로"와 같은 구조다.
- 홀의 앰버·브라운 색이 Moments 브랜드 색(#241C18 / #EDE9DD / #E08566)과 거의 같다.

## 가져온 것과 이유
| 가져온 것 | 이 영상에서 | 이유 |
|---|---|---|
| 두 세계 교차 편집 | 0.5–17.5s: 한 사람의 제주 사진(청회색) ↔ 다른 사람의 사진(따뜻한 톤), 8컷 | "따로"를 말없이 보여 준다 |
| 따뜻한 쪽으로 가는 컷은 음 시작점, 차가운 쪽으로 가는 컷은 숨 | 2.5 / 6.75 / 11 / 15.25s에 프레이즈 시작, 4.5 / 9 / 13s 앞에서 바이올린이 쉼 | 레퍼런스 실측: 33컷 중 13컷이 음 시작점, 6컷이 숨 |
| 가장 조용한 곳에서 처음 섞임 | 17.5s 실제 Moment 화면에서 두 사람의 사진이 나란히(청회색이 빠지며 같은 톤이 됨) | 레퍼런스 54.5s |
| 최고음 = 한 프레임, 컷 1개 | 30–33.4s E6를 끌고, 화면은 "제주, 우리 셋의 첫 여행." 전체 하나 | 레퍼런스 64.5–69s |
| 컷을 넘어가는 얇은 카드 | "따로 찍은 사진이," (컷을 넘어 유지) / "하나의 순간으로." | 움직이지 않는 글자가 장면을 잇는다 = "묶는다" |
| 음악 끝 → 0.5s 침묵 → 로고 한 음 | 37.8–38.3s 진짜 침묵(잔향까지 차단), 38.3s 제목의 주황 마침표가 로고의 마침표가 되며 피아노+하프 한 음 | 레퍼런스의 사운드 로고 |

## 주인공 오브젝트
제목 "제주, 우리 셋의 첫 여행." 끝의 **주황 마침표**. 침묵 속에 혼자 남아 있다가 로고의 마침표가 된다.
