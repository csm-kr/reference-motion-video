# Moments 60s — 오케스트라 "우리의 명장면"

## 레퍼런스와 고른 이유
**Google Photos "Best Picture"** (2017, https://www.youtube.com/watch?v=tOb_bgnk4dY). 분석 원문: `../refs/orchestral/ANALYSIS.md`.

- 사진 서비스가 "평범한 순간이 곧 명장면"이라고 말하는 광고다. Moments의 감정선과 같다.
- 클라이맥스 연출이 Moments의 핵심 기능과 같은 모양이다. 사진 한 장 → 같은 날 사진들이 깔림 → 앱 화면으로 줌아웃. "따로 올린 사진이 하나의 Moment로 묶인다"를 설명 없이 보여 준다.
- 음악 구조가 60초 안에서 완결된다(조용한 도입 → 16초 진입 히트 → 빌드 → 2.5초 스웰 → 로고에서 IV→I).

## 가져온 것과 이유
| 가져온 것 | 이 영상에서 | 이유 |
|---|---|---|
| 조용한 도입 + 문장 단위 컷 | 0–13.3s 사진 5장, 마디마다 컷, 자막 칩이 한 줄씩 이어지는 문장 | 레퍼런스는 VO 문장 단위로 끊는다. 우리는 VO 대신 자막 칩을 쓴다 |
| 16초 진입 히트 = 큰 공개 | 검색 결과가 팀파니·베이스드럼 히트 프레임에 뜬다 | 레퍼런스의 "big reveal"(고래)과 같은 자리. 기능 시연이 감정의 정점이 된다 |
| 고른 빌드 | 24.7–45.3s 스피카토 8분음표(0.333s, 레퍼런스 0.355s) | 장면은 바뀌어도 맥박이 이어져 하나의 흐름이 된다 |
| 박마다 사진 컷 | 45.3–50.7s 사진 8장, 한 박(0.667s)마다 하드 컷 | 레퍼런스 46–50s 사진 연속 컷(0.83–0.92s)과 같은 문법 |
| 히어로 사진 → 형제 사진 → 줌아웃 | 노을 가족 사진 → 같은 Moment의 다른 사진 22% → 실제 "제주, 우리 셋의 첫 여행." 화면 | 핵심 기능을 그대로 보여 준다 |
| 해결은 로고와 같은 프레임 | 제목 끝 주황 마침표가 날아가 로고의 마침표가 되는 53.333s에 C장조 해결 | 브랜드가 결론처럼 들린다 |
| 엔드카드 두 박 | "흩어진 순간을," / "하나의 Moment로." → CTA | 레퍼런스의 "Photos." / "For life." 구조 |

레퍼런스와 다르게 한 것: 화면 글자가 없는 레퍼런스와 달리 자막 칩을 계속 띄운다(고정 틀). 중반 장르 몽타주 대신 실제 앱 화면(검색, 댓글, 업로드, 자동 묶기, 초대)을 넣었다. 기능을 증명해야 하기 때문이다.

## 주인공 오브젝트
- **노을 가족 사진**: 검색으로 찾고 → 댓글을 달고 → 마지막에 자기 Moment의 타일로 돌아간다.
- **주황 마침표**: 모든 Moment 제목 끝에 있는 제품 고유의 점이다. 마지막에 로고의 마침표가 된다.

## 소리
- 악보와 효과음 모두 `score.py`가 영상의 신호(`cues.json`)에 맞춰 코드로 만든다.
- 악기: VSCO-2-CE 오케스트라 샘플(CC0). 현악 섹션, 콘트라베이스, 호른, 트럼펫, 하프, 글로켄슈필, 팀파니, 베이스드럼, 심벌.
- 효과음: Pixabay 라이선스(크레딧 불필요).
- 마스터: −16 LUFS, 최고 레벨 0.84.
